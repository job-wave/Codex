# 자소서 비포·애프터

Public pages at `/stories` and `/stories/[slug]` provide four original fictional examples: two student cases (team projects, part-time work) and two professional cases (operations improvements, career changes). All cases identify their fictional status and explain what changed between the vague and concrete versions. No hiring outcomes or fabricated user achievements are claimed.

The client-only workshop asks four case-specific questions, validates trimmed answers of 10–600 characters, renders them with `textContent`, and joins them for copying. It does not call an AI model, submit answers, use browser storage, or save to a member account. Any edit hides the previous draft to prevent copying stale answers. Each case offers a self-check and related mission. The existing authenticated experience-record entry point is reused; users must copy their draft before leaving, and the page explicitly says it is not transferred automatically.

Discovery uses a compact link within the homepage's existing guide section, the support-preparation view, the guide list, and the public content header. The sitemap includes the list and all four detail pages. Existing authentication, job collection and member records remain unchanged.

Validation: existing guide, homepage and mission regression checks; public case/filter/metadata/404 and escaping checks; browser checks for empty submission, draft creation, copying and invalidation on edit; desktop and 390px layout review.
