## Unattended publishing contract

`GET /api/insights` provides the current version, edition, front-page selections and up to 60 recent archived articles plus selected/fallback articles. `GET /editorial-update-contract.json` is the versioned public cloud-run contract. The task obtains the current Site URL and service token via Sites `get_site` at run time, without retaining or displaying the token. It sends it in the platform `OAI-Sites-Authorization` header and the separate application `X-Jobwave-Editorial-Token` header. `INSIGHTS_REFRESH_TOKEN` is configured as a hosted secret; after intentional service-token rotation, refresh this binding through native Sites environment tools. Never store the value here.

`POST /api/insights/refresh` validates authorization, optional same-origin header, a strict bounded schema, official HTTPS source URLs, real calendar dates, source verification evidence, selected article kinds and optimistic version. Updates preserve original publication dates. Each write uses a unique run ID and content fingerprint, with identical retries recognized. D1 batches the selection and archive upserts atomically; losing a version race writes no article changes, and write failures preserve the prior selection. A no-op run can skip POST. Failed source checks leave that article unchanged. Archive URLs remain readable after they leave the front page.

`scripts/editorial-client.mjs` accepts its token only through non-echoing stdin and logs only status metadata. Normal updates require an explicit update payload; `verifyExisting:true` is reserved for setup verification of already checked current content. It performs authenticated read/write/readback. No OpenAI API call, new API key, reader account or redeployment is needed per run.

Server tests use real in-memory SQLite to cover permission rejection, source/date bounds, stable retry, archive retention, original-date preservation, transaction rollback, version races and storage failure. Production readiness is verified using current service access and unchanged original seed content before creating the linked schedule.
