# 채용 수집처 확장 (2026-10-24)

현재 기업 공식 수집처 9개: 쿠팡, 몰로코, Delight.ai(센드버드), 마크비전, Anthropic, 아고다, 데이터독, 데이터브릭스, 몽고DB.
국내 근무지 명시 공고만 수집하며 제목 기반 경력 분류는 참고 표시한다. 마감일을 추정하지 않는다.

## 사람인 — 코드 준비, 키 미연결
- 신청: https://oapi.saramin.co.kr/guide/info
- 승인받은 앱 키를 Sites 서버 비밀 환경변수 `SARAMIN_ACCESS_KEY`에 입력한다. 채팅/소스에 키를 넣지 않는다.
- 서비스 이용조건과 승인된 표시 범위를 확인한 뒤 연결한다.
- 활성화 시 1회 호출로 최신 공고 110건을 수집한다. 전체 사람인 공고 수집이 아니다.
- 응답 원문 링크의 출처 추적 파라미터를 유지한다. 별도 본문 스크래핑 없음.
- 정상 응답 저장, 인증/제한/응답오류 시 기존 스냅샷 보존.
- 키 없이 정규화/오류 보존 테스트만 수행; 실제 승인 API 호출 검증은 키 연결 후 필요.

## 잡알리오 — 신청 대기, 수집 어댑터 미연결
- 공식 신청: https://www.data.go.kr/data/15125273/openapi.do
- 개발 자동승인 / 운영 심의승인. 기관 채용정보와 접수기간·접수방법 제공.
- 승인 후 제공되는 최신 명세/샘플 응답과 인증키로 목록/상세/마감 처리 구현·검증 후 활성화한다.
- 인증키나 현재 API 경로를 추측해 연결 완료로 표시하지 않는다.
